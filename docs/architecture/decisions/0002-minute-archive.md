# ADR-0002：独立分钟档案及逐轴资格

<!-- lifecycle:registry -->
读者：架构/开发/运营；责任：架构维护者。源码核验：2026-10-27；每30日及分钟档案合同变化复核。目标生产另验，见[文档治理](../../development/DOCUMENTATION_GOVERNANCE.md)。
<!-- /lifecycle -->

状态：采纳候选校验合同，2026-10-27；存储适配器、自动采集调度和目标长期运行尚未实施。
权威消费规则在[应用调用约定](../../development/APPLICATION_INTEGRATION.md)，可执行入口为
[audit_minute_archive.py](../../../scripts/validation/audit_minute_archive.py)。

公开节点的0feb正文没有回显交易日期，时间标签由本地生成。全价格参照只赋予当前响应的日期资格；
它不赋予时间、均价、量额单位或全日完整性。真实样本存在边界差异，跨节点一致也不能替代独立参照。
把这些响应按请求日期直接放入日线发布表，会丢失其独立证据和修订责任。

选择按`archive_id/revision/(market, code, date, slot)`维护独立JSONL分钟候选，
逐轴声明日期、槽位、价格、成交股数、人民币分金额的独立证据。第一阶段提供有界只读校验和稳定
重放摘要，不引入新的数据库schema、异步运行时或长期服务。自有档案只覆盖其独立核实的采集范围；
历史回补必须走相同校验，不能将公开源的单点采样下界写成完整保存期。

| 边界 | 决策 |
| --- | --- |
| 日期与槽位 | 点时应有名单逐日声明Trading/Suspended/Delisted；Trading明确列出全部有序槽，其他状态槽为空，均须独立公告/日历/时段证据。不得填造09:30或用默认240点证明所有证券完整 |
| 原始取得 | 每个分区固定endpoint、captured_at、response摘要；RequestedRefresh另存request；PassivePush禁止关联请求且须有无请求时段/消息身份原证据；ArchiveReplay保留原取得来源证据 |
| 量额闭合 | 行使用非负整数股数与人民币分，累计值逐槽精确闭合，末槽与独立全天控制总额精确一致。没有单位证据不得把原始量转换为股数 |
| 修订与缺口 | 每版保留原字节；revision与source_as_of不回退，同revision内容冲突拒绝。必需分区/槽缺失或额外时返回incomplete，不发布部分范围 |
| 保存与资源 | days、max_bytes、max_files、max_freshness_seconds均为部署前必填输入；缺少值不能通过。预算覆盖声明目录所有文件，此外有校验器硬上限 |
| 恢复与回放 | 原文件逐一核对字节和SHA，按有序分区键及JSONL摘要计算replay_sha256；重放只恢复原版本，不凭重放升级真实来源资格 |

与上一版比较时，声明保存窗口内丢失的已存分区使校验失败。此检查只覆盖交给校验器的上一版，
持续保存期还需要不可变存储、完整版本历史、备份清单、定期恢复和独立运营审计。目录扫描的逻辑
字节不能替代文件系统硬配额或远端备份配额。未配置保存期及新鲜度时保持未验收。

`covered`仅指声明范围、固定字节、结构和调用方填写的独立资格一致；它不证明外部公告语义正确、
提供商实际具备被动推送，或生产已经保存了规定年限。返回中的`passive_push_verified`保持false，
实时能力验收仍按[生产矩阵](../../testing/PRODUCTION_ACCEPTANCE.md)留原请求/帧/时间线证明。

验收包含缺槽/额外槽、量额资格缺失、日闭合分歧、过旧档案、未填保存输入、改raw、符号链接、
重复分区、请求刷新冒充被动帧及跨版本回退/丢失保存分区；构造夹具不升级为市场验收证据。
此合同可由后续存储适配器消费；在业务范围与保存输入确定前不自动接入现有日线catalog。
