# 2026-10-24 K线成交量验证支持包

[验证报告](../../KLINE_VOLUME_UNITS_20261024.md) · [机器可读结论与文件摘要](../kline-volume-units-20261024.json)

此目录保存本轮真实样本，不覆盖`tests/fixtures/kline`或10月23日研究证据。采样在UTC+8的10月24日进行；`capture.json`原样保存UTC的10月23日23:49时间。

| 文件/目录 | 内容 |
| --- | --- |
| `capture.json` | 一次握手、24次K线请求的时间、服务器、帧长度和请求/响应摘要；没有线上失败 |
| `wire/*.request.bin` | 实际发出的完整请求 |
| `wire/*.frame.bin` | 服务端完整响应帧，含16字节头及压缩正文 |
| `wire/*.body.bin` | 解压后的响应正文 |
| `official-day/*.day` | 官方ZIP中选定的四个完整成员；股票、ETF和指数分别保留源单位解释 |
| `provenance.json` | 完整ZIP摘要、选定成员、固定源码和原生补采二进制的摘要 |
| `native/` | 既有本库原生程序补采的3类各3根请求/正文、独立pytdx生成的期望CSV及参考源码摘要 |
| `results.json` | 全部928条双公式解码、144条日线对照、12组成对响应、分钟整日聚合及合成边界 |
| `verification/` | 本轮捕获输出、离线重放及现有原生测试二进制的运行日志 |
| `validate.py` | Python标准库脚本；默认离线核验，只有显式`--capture`才发起有限只读请求 |

从仓库根目录离线重放：

```sh
python3 docs/validation/evidence/kline-volume-20261024/validate.py
```

脚本先验证固定源码、支持文件及原始报文摘要，再核对请求参数、解码、独立pytdx CSV、日线价格/金额/量、分钟聚合和长度成对结果，重新生成`results.json`。默认不会连接服务器。

再次采样必须使用新的输出目录，不会覆盖现有`wire/`。同一脚本的捕获功能上限为120秒，一个同步连接，24个固定参数请求；新采样的数据窗口可能改变，不能当作本次固定样本的逐字节复现。

完整ZIP来源引用[前轮真实下载证据](../round3-real-day-databases.json)，本包仅复制其四个成员。`.day`和7709来自同一供应商不同表示；没有执行完整eltdx SDK、改变Rust生产换算或验证全部周期。该轮未定位到仓库内工具链，原生二进制当时未重建；原生补采只证明当时本库解码器接受9根记录，独立数值核验另由参考解析及源码转写完成。后续已定位到本地Rust1.89工具链，当前源码构建与回归另见[验证记录](../../TDX_ONLY_VALIDATION_20261024.md)。
