# rustdx 分阶段迭代

范围限定为现有行情库、文件解析、计算模块和 CLI。保持同步 Rust 及 workspace 结构。

| 阶段 | 交付内容 | 状态 |
| --- | --- | --- |
| 1 正确性 | 稳定连接归还、完整帧重试、安全解析、分页、增量因子、代码日期、导入错误 | 完成 |
| 2 数据语义 | 标准类型、日历时段、质量校验、采集记录、数据库一致性 | 完成 |
| 3 性能与交付 | 有界管道、缓存/下载、增量计算、CI、发布 | 完成 |
| 4 项目使用能力 | 可用的 API/CLI、示例、迁移文档与整体验证 | 待完成 |

第一阶段验证：离线 workspace 测试（含5个本地可靠性回归）、文档测试及 Clippy 均通过。原有网络案例由 `RUSTDX_SKIP_INTEGRATION_TESTS=1` 跳过；连接池回归使用本地协议服务器。

第一阶段行为变化：

- `auto_reconnect` 表示首试之外的重试次数，正文截断和解压错误会使连接失效。
- `Tdx::try_parse` 返回解析错误；旧 `parse` 保留兼容入口，内置协议的失败结果清空。
- 池永久关闭，不允许关闭后重新获取；连接池继承 `TcpConfig`。
- 日K统一分页/去重；无进展、非法日期及偏移耗尽返回错误。
- 东财导出代码含市场前缀，日期来自源 `f124` 时间戳，正式日线需收盘确认；字段提高到 f64。
- 前因子文件只读，解析失败不再忽略；无除权事件也继承前因子。
- ClickHouse factor读取使用同一HTTP配置；导入后辅助查询失败不会误报写入失败。

第二阶段验证：离线 workspace 测试及 Clippy 通过。新增市场/单位、午休边界、单日缺口/重复/长假、停牌事件全量与增量一致性、坏文件原子输出及质量报告测试。

第二阶段行为变化：

- 新增 `data::Symbol/Market/Bar/VolumeUnit`，标准行情使用股和 UTC+8；CSV 保留手的单位。
- 内置休市表明确覆盖2024–2026，新严格日历接口拒绝范围外估算；午休不再算交易时间。
- NaN、OHLC范围、日期重复与逆序返回错误；缺口标记原因待核实。
- `day --report` 写入采集质量 JSON，`--strict` 对未核实缺口也失败；输出原子替换。
- 累计收益因子按时间应用停牌期间除权事件；gbbq分组不再依赖文件排列顺序。
- 新 ClickHouse 表使用 `ReplacingMergeTree(version)`；旧表明确要求迁移，见 `MIGRATION.md`。

第三阶段验证：离线 workspace 测试、下载模块本地 HTTP 续传与 ZIP 回归、Clippy 通过。Rust 1.89.0 全 workspace/all-targets 检查通过。100k行SMA+RSI、10轮 release 基准：周期20约42ms、200约27ms、2000约23ms（本机观测，不作为CI性能门槛）。

第三阶段行为变化：

- 默认内存缓存4096条/64MiB，可自定义容量；过期清理、稳定文件键、原键校验、原子写入及显式 `try_*` 错误接口。
- 同一键并发获取合并；固定64个锁限制同步结构占用，碰撞键可能串行。
- 下载使用 `.part` 和 `If-Range`；检查 Content-Range、长度及ZIP目录后发布；缓存要求远端版本标识，离线使用显式本地ZIP。
- 下载/本地ZIP按来源隔离并用系统文件锁；解压先写临时目录，失败保留上次有效目录；非交互环境不等待输入。
- CLI `--workers`（1–64，默认最多8）、结果有界通道、排序选取文件、单个day文件32MiB限制。
- SMA/RSI O(n)滚动计算及 `RollingSma` 流式接口，KDJ预热/缺口返回None，横盘RSI为50。
- CI覆盖Linux/macOS/Windows及MSRV；tag触发正确包名的release构建，草稿发布带SHA256校验文件。
