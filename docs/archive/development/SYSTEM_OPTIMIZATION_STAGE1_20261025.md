# 系统优化第一阶段：CI、管理边界与恢复巡检

来源为[A01–A12方案](../architecture/SYSTEM_OPTIMIZATION_PLAN_20261025.md)，基线`47045cd554de2f3237a7f2f2821146b47807c43b`。本阶段完成A01–A04工程及回归，补A05维护工具和A11数据库CI触发/工具固定。生产规模、完整事实及远端新源码执行单独判定。

期限、父子上下文和取消测试分别使用确定性到期注入、上下文deadline比较和线程就绪信号。保留取消与父期限行为检查，去除“60ms中先睡40ms”的调度假设。CI矩阵关闭fail-fast，质量检查为独立任务，工作区严格文档和所有任务超时已配置；尚未推送新配置，不把本机回归解释为远端通过。

管理查询使用`Ledger::open_existing_readonly`，缺账本或不兼容schema拒绝；`open_writer`核对根锁，兼容`open`在初始化/迁移时排他。新增`migrate`管理入口。SQLite只读连接可能使用WAL/shm，不声称任何打开均零写辅助文件；严格无源写巡检保留私有WAL快照。

备份/恢复规范化已有父目录，拒绝别名落入源目录、`..`及已有目标。备份先预留SQLite、全部文件和固定长度SHA清单，分步复制继续核预算；成功清单和恢复标记也计入上限。新备份数据库为完成的独立DELETE模式快照；第一次紧预算恢复测试发现额外SQLite辅助文件后修正，源冻结材料未变。恢复持根锁，完成标记保存`original_roots`，旧账本路径不重写。

留存工具根据经过验证的恢复标记把历史Attempt映射到当前`attempts/<id>`；原root离线仍可巡检。catalog中的`Receipt.proof`及`targets.proof`原文件和内嵌请求/响应摘要分别验证；工具仍只预览，无删除或裁剪。

事实维护登记涵盖规则、年度日历、上市/退市、ST/停复牌和点时名单，包含维护/独立复核/升级角色、声明范围、核实日期、下次复核日、原来源及SHA。脚本拒绝同角色自审、摘要变化和路径越界；缺资料或复核到期返回attention_required。示例五类均明确无事实资格，不能当作真实全市场数据；运营方落实角色和实际资料后再独立审阅。没有发送消息或自动续期。

数据库验收新增main变更触发及管理回归；两个工具归档分别从既有官方HTTPS地址取得，固定本次实际SHA后在CI解压前核对。官方单独`.sha256`地址返回403；本次固定的是HTTPS来源实际归档字节，不宣称厂商数字签名。工具没有在本机执行。原URL、字节数和本机SHA核对结果保存于支持包。
