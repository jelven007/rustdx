# 日期化涨跌幅规则

核实日期：2026-10-22。`RULE_VERSION = exchange-rules/2026-07-06`。主板规则查询覆盖2014-01-01起，创业板2009-10-30起，科创板2019-07-22起，北交所2021-11-15起；均截止核实日期。范围外返回错误，不推测旧制度或未来政策。

对应源码7cd02e7及后续优化，尚未发布新crate版本。业务使用与证券事实维护见[OPERATIONS.md](OPERATIONS.md)，接口和迁移见[DEVELOPMENT.md](DEVELOPMENT.md)、[MIGRATION.md](MIGRATION.md)。外部日历扩展不会自动扩大本规则核实范围。

`RuleContext` 必须包含行情日期、当日ST状态及经上市公告确认的阶段。IPO使用**交易日序号**（首日为1），不能用自然日计数；是否注册制须由上市资料确认，不能只根据查询日期推断。市场休市日检查由 `CalendarProvider` 承担。

旧核准制IPO首日返回 `LegacyIpoFirstDay`，因为发行价基准及当时专门规则不能用昨收/板块比例替代。公告明确的重新上市、退市整理首日或其他无幅度限制日使用 `AnnouncedUnrestricted`。未股改S股、特别停复牌、不同最小报价单位及证券类型尚不包含在自动规则选择中。

`prices_at` / `status_at` 无幅度限制时返回 `Ok(None)`；非法价格和不支持的制度返回 `Err`。普通股票价格四舍五入到分，并处理至少一个报价单位及最低一分的边界。现有静态 `limit_up_price`、`limit_down_price`、`limit_status` 接口保留，幅度使用2026-07-06规则，历史回测应改用日期接口。
